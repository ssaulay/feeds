# Exa transforme Claude en agent capable de rechercher sur le web en temps réel

> Post de **@jeffzwang** — [voir sur X](https://x.com/jeffzwang/status/2047736429221224900)

## Résumé

Exa lance un plugin pour Claude donnant accès à des milliards de sites web, docs, papers, profils et entreprises. Ce plugin permet à Claude d'agir comme un recruteur, un vendeur, un chercheur ou un ingénieur fiable. L'installation se fait simplement via des commandes dans le terminal (marketplace update, install, puis authentification MCP).

## Idées clés

- Un plugin MCP peut étendre drastiquement les capacités d'un LLM en lui donnant accès à une recherche web massive et structurée.
- Exa positionne son outil comme un multiplicateur de rôles pour Claude (recruteur, sales, chercheur, ingénieur).
- L'installation et l'authentification se font en une ligne de commande via le plugin marketplace officiel de Claude.
- La comparaison avec la scène 'apprentissage du kung-fu' de Matrix illustre l'acquisition instantanée de nouvelles capacités par un agent IA.
