# Transformer des cadres photo Amazon à $50 en écrans d'affichage intelligents

> Post de **@wesbos** — [voir sur X](https://x.com/wesbos/status/2108550413599265045)

## Résumé

Wes Bos explique comment des cadres photo connectés bon marché (environ $50 sur Amazon) sont en réalité des tablettes Android déguisées, qui peuvent être rootées pour faire tourner un navigateur moderne. Il détaille dans une vidéo comment il a réparé le calendrier Skylight défectueux de sa sœur avec un dongle WiFi USB à $11, puis reproduit le hack sur un cadre générique. Tout le code est disponible sur GitHub pour créer son propre dashboard domestique.

## Idées clés

- Les cadres photo smart à bas prix sont des tablettes Android cachées, exploitables pour d'autres usages que prévu par le fabricant
- Un agent de codage IA a aidé à trouver un mode debug caché pour rooter l'appareil
- Le hack fonctionne avec une résolution 1280x800 tactile, alimenté en USB, avec WiFi
- Ces appareils sont souvent un cheval de Troie pour vendre un abonnement mensuel, alors qu'on possède le matériel
- Le dashboard résultant peut afficher calendrier, météo, tâches ménagères et photos en temps réel
- Le code complet est open-source sur GitHub (wesbos/photo-frame-dashboard)
