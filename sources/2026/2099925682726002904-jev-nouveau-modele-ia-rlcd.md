# Lancement de Jev : un modèle IA frontier optimisé pour les décisions via RLCD

> Post de **@CompleteSkeptic** — [voir sur X](https://x.com/CompleteSkeptic/status/2099925682726002904)

## Résumé

Un co-inventeur de ChatGPT annonce Jev, un nouveau modèle d'IA développé après deux ans en stealth mode, entraîné avec une nouvelle méthode appelée RLCD. Le modèle serait 20 à 200x plus rapide et 40 à 400x moins cher que les modèles actuels, avec les tokens de sortie gratuits, et se positionne comme une intelligence composable optimisée pour la prise de décision plutôt que pour le chat.</br>L'auteur présente ce lancement comme le chemin le plus court vers une révolution économique basée sur l'IA, questionnant pourquoi les modèles de chat superhumains n'ont pas encore mené à l'AGI.

## Idées clés

- Une nouvelle méthode d'entraînement (RLCD) est présentée comme rupture par rapport aux approches actuelles de chat models
- Le positionnement stratégique vise la 'décision' plutôt que la conversation, un angle différent des LLM généralistes
- Les gains annoncés (vitesse et coût) sont massifs et pourraient rebattre les cartes de l'accessibilité économique de l'IA
- La gratuité des tokens de sortie change le modèle économique classique des API LLM
