# CS146S: cours Stanford sur le développeur logiciel AI-native (Fall 2026)

> Post de **@nummanali** — [voir sur X](https://x.com/nummanali/status/2095185152112529834)

## Résumé

Mihail Eric annonce la nouvelle édition de son cours Stanford 'The Modern Software Developer', entièrement repensé suite au bond de capacité des agents de code (Claude Opus 4.5). Le cours forme les développeurs AI-native de demain avec 85% de contenu renouvelé, un focus sur les agents de code, le context engineering, MCP, et une collaboration inédite avec des repos open-source réels pour que les étudiants shippent du code en production. Toutes les ressources et sessions seront publiques.

## Idées clés

- Les développeurs AI-native deviendront les membres les plus importants de toute organisation logicielle selon l'auteur du cours.
- Le syllabus 2026 couvre agent skills, context engineering avancé, MCP portals, principes de codebase agent-ready, revue de code agentique, sécurité, et parallélisation d'agents en arrière-plan.
- Innovation pédagogique majeure : les étudiants doivent contribuer via des pull requests à des codebases open-source réelles (Browserbase, HeyGen, Vercel, CrewAI, etc.) avec mentorat des équipes.
- Des intervenants de premier plan (Cursor, Claude Code, Replit, Cognition, Cloudflare) partagent leurs retours d'expérience sur la construction de produits d'agents de code.
- Tout le matériel de cours et les sessions sont rendus publics et gratuits, démocratisant l'accès à une formation de pointe.
