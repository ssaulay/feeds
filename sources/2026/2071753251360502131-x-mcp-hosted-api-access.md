# Lancement du X MCP hébergé : accès à l'API X pour les outils IA compatibles MCP

> Post de **@taycaldwell** — [voir sur X](https://x.com/taycaldwell/status/2071753251360502131)

## Résumé

X (anciennement Twitter) lance un serveur MCP hébergé permettant d'utiliser l'API X directement depuis n'importe quel outil compatible MCP (Grok, Cursor, etc.), avec les permissions du compte utilisateur et sans configuration nécessaire. Cela permet aux agents IA d'accéder à des informations en temps réel depuis la plateforme X.

## Idées clés

- Le X MCP permet de connecter des outils IA (Grok, Cursor, etc.) à l'API X sans setup complexe.
- L'accès utilise les permissions propres du compte de l'utilisateur.
- Positionné comme donnant aux agents IA accès à une source d'information temps réel majeure.
