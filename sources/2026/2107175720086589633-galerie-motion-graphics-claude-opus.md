# Galerie de motion graphics générés par Claude Opus 5.5 avec prompts associés

> Post de **@p4nthera_** — [voir sur X](https://x.com/p4nthera_/status/2107175720086589633)

## Résumé

Un créateur a constitué une bibliothèque de 226 animations/motion graphics réalisées avec Claude Opus 5.5, chacune accompagnée du prompt ou du skill utilisé pour la générer. Les contributions sont collectées depuis X et créditées à leurs auteurs d'origine, formant une ressource consultable filtrable par prompt ou par skill.

## Idées clés

- Claude Opus 5.5 peut générer des animations et motion graphics variés (particules, formes géométriques, UI animées) à partir de prompts textuels
- Documenter le prompt exact à côté du résultat visuel facilite l'apprentissage et la reproduction de techniques de génération
- Une curation communautaire (crowdsourcing depuis X) permet de construire rapidement une bibliothèque de référence pour un cas d'usage IA spécifique
- La distinction entre 'prompt' et 'skill' suggère deux approches différentes pour obtenir des résultats avec un LLM : instruction directe vs compétence/méthode réutilisable
