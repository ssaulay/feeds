# Treg : recherche de personnes low-cost pour agents IA via Claude

> Post de **@jasonzhou1993** — [voir sur X](https://x.com/jasonzhou1993/status/2094740336895840605)

## Résumé

Treg est un outil open source qui donne aux agents IA (comme Claude) accès à plus d'1 milliard de contacts via 60 fournisseurs de données (Apollo, Hunter, Tomba, etc.), avec paiement à l'usage sans markup. Il permet de trouver des emails vérifiés, numéros de téléphone, d'enrichir des profils/entreprises et de détecter des signaux d'achat, pour environ $0.0089 par lead contre $600/mois pour des solutions classiques. Sur le benchmark People Search Bench, Claude Code seul répond correctement à 43% des tâches, contre 78.2% avec treg.</p>

## Idées clés

- Treg agrège 60 fournisseurs de données de contacts derrière un seul token API, avec paiement uniquement pour les résultats obtenus.
- Le coût par email vérifié tombe à $0.0089, une fraction du prix des abonnements SaaS traditionnels (~$600/mois).
- L'outil couvre un large éventail de tâches : recherche de personnes/entreprises, vérification d'emails, détection de signaux de recrutement/financement, et bien plus (SEO, réseaux sociaux, scraping).
- Le benchmark 'People Search Bench' montre un gain de performance significatif pour les agents IA équipés de treg (78.2% vs 43% pour Claude Code seul).
- Le projet est entièrement open source et accessible via github.com/LessieAI/people-search-bench.
