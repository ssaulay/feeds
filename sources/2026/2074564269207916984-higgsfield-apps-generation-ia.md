# Higgsfield Apps : génération d'applications complètes par IA

> Post de **@adilinthewild** — [voir sur X](https://x.com/adilinthewild/status/2074564269207916984)

## Résumé

Higgsfield lance sa plus grosse release à ce jour, appelée Higgsfield Apps, qui permet de générer des applications intégrant nativement les modèles d'image et vidéo de Higgsfield. L'outil s'appuie sur un moteur nommé Fable 5 pour concevoir chaque application comme le ferait un ingénieur senior, couvrant sites web, extensions navigateur, plugins et applications desktop/mobile, avec déploiement direct. La solution est disponible sur Supercomputer et via Claude grâce au MCP Higgsfield.

## Idées clés

- Higgsfield Apps permet de générer des applications avec les modèles d'image/vidéo Higgsfield intégrés nativement
- Le moteur Fable 5 conçoit le code applicatif au niveau d'un ingénieur senior
- L'outil couvre un large spectre : sites web complexes, extensions, plugins, apps desktop et mobile
- Déploiement direct possible une fois l'app générée
- Intégration disponible via Claude grâce au protocole MCP (Model Context Protocol) de Higgsfield
