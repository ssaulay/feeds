# QM : le harness multi-agent open source de YC pour Slack et le web

> Post de **@garrytan** — [voir sur X](https://x.com/garrytan/status/2083353760701833546)

## Résumé

YC a open-sourcé QM, un harness multi-agent utilisé en interne pour piloter des IA sur des tâches variées (comptabilité, légal, événementiel, ingénierie). Sous licence MIT, il est cloud-first et propose nativement une interface Slack et web. L'outil permet de gérer des sessions, projets, chats, fichiers, webhooks, crons et mémoire pour orchestrer des agents IA au sein d'une équipe.

## Idées clés

- QM est conçu pour être facilement personnalisable, à la manière de Hermes ou OpenClaw, mais pensé pour un usage à l'échelle d'une entreprise entière.
- L'outil est utilisé en interne chez YC dans plusieurs départements : comptabilité, légal, événements et ingénierie (y compris pour développer QM lui-même).
- L'interface propose une navigation par Projets, Chats, Fichiers, Webhooks, Crons, Keychain, Deploys, Memory et Skills.
- Les agents peuvent exécuter des tool calls (recherche, lecture de fichiers) et produire des artefacts comme des visualisations ou des exports CSV.
- Le projet est entièrement gratuit et open source sous licence MIT.
