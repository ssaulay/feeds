# Miso One : un modèle text-to-speech ultra-expressif en open source

> Post de **@ian_dot_so** — [voir sur X](https://x.com/ian_dot_so/status/2062269826177868211)

## Résumé

Miso One est un modèle de synthèse vocale de 8 milliards de paramètres capable de générer une parole hautement expressive avec seulement 110 millisecondes de latence, soit plus rapide qu'une réponse humaine. Les poids du modèle sont déjà open-source, avec un accès API prévu prochainement. Le post original souligne que ce type d'avancée va rendre les interactions vocales avec l'IA de plus en plus troublantes de réalisme.

## Idées clés

- Miso One atteint une latence de 110ms, plus rapide que le temps de réponse humain typique.
- Le modèle est décrit comme le plus émotif au monde en matière de synthèse vocale.
- Les poids sont open-source dès maintenant, favorisant l'expérimentation par la communauté avant même l'arrivée de l'API.
- La miniaturisation (8B paramètres) permet une expressivité élevée sans nécessiter un modèle massif.
