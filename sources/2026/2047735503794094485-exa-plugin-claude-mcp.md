# Exa lance un plugin MCP pour donner à Claude un accès web massif

> Post de **@ExaAILabs** — [voir sur X](https://x.com/ExaAILabs/status/2047735503794094485)

## Résumé

Exa propose désormais un plugin officiel pour Claude, exploitant le protocole MCP pour donner accès à des milliards de sites web, documents, papiers de recherche et profils (personnes/entreprises). L'installation se fait simplement via le CLI Claude en utilisant le marketplace officiel de plugins. L'objectif est de transformer Claude en un agent polyvalent capable d'agir comme recruteur, commercial, chercheur ou ingénieur selon le contexte.

## Idées clés

- Un plugin MCP peut étendre les capacités de Claude en lui donnant accès à des sources de données externes massives.
- L'installation se fait en une ligne de commande via le marketplace officiel de plugins Claude.
- Un seul plugin peut transformer un LLM généraliste en agent spécialisé selon le use case (recrutement, vente, recherche, ingénierie).
- Exa se positionne comme infrastructure de recherche web pour les agents IA plutôt que comme simple moteur de recherche grand public.

Introducing Exa for Claude:
