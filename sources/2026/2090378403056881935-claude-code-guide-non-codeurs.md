# Guide pratique pour construire des sites et outils avec Claude Code sans coder

> Post de **@claudeskills101** — [voir sur X](https://x.com/claudeskills101/status/2090378403056881935)

## Résumé

Ce post explique comment utiliser Claude Code pour construire des sites web, mockups et petits outils sans écrire une ligne de code, en décrivant simplement ses besoins en langage naturel. Il détaille le setup, le prompt type, la boucle de travail itérative, et les astuces pour éviter les designs génériques et maîtriser les coûts.

## Idées clés

- Claude Code s'adresse à ceux qui veulent construire des sites, mockups ou petits outils fonctionnels, pas de simples docs, images ou widgets ponctuels
- Le setup optimal : Pro $20, bypass permissions activé, connecteurs Netlify + Supabase, modèle Opus 5 en High
- Le prompt gagnant consiste à positionner Claude comme CTO, interviewer l'utilisateur question par question, présenter un plan avant de builder et déployer directement sur Netlify
- La boucle de travail efficace : screenshot d'un site aimé, lister les corrections en langage clair et numéroté, itérer par rounds de six par page
- Utiliser getdesign.md pour appliquer un style professionnel (Stripe, Notion, Linear) plutôt que de demander vaguement de 'faire joli'
- Ouvrir un nouveau chat par tâche et pointer vers les fichiers plutôt que copier-coller du texte pour économiser les coûts, car chaque mauvais tour se paie

## Texte du post

You won't write a line of code. It builds websites, mockups, and small tools, you describe them, you never write code.

It's not for you if you want a simple doc or excel (that's Cowork), just an image (that's ChatGPT), a widget you'll open once (that's an Artifact), or a small interactive interface (that's Claude Chat). Still here? Then it's for you.

Setup takes 5 minutes: https://t.co/rJz6BGrNwX → Pro $20 → Code tab, make one empty folder, turn on bypass permissions, add Netlify and Supabase as connectors, set the model to Opus 5, High.

The prompt that works: tell Claude it's your CTO, you don't read code, plain English only. State your end goal, have it interview you one question at a time with AskUserQuestion, show the plan, then build and push live with Netlify. A live booking site: 24 minutes.

The constant loop: screenshot a site you like and say "build me this, but for my thing," list what's wrong in plain numbered words, paste it back, six rounds per page, manually permit as you go.

What to build: a landing page with offers and a booking button, a clickable mockup of the thing you keep failing to explain, a tool that turns your export into a clean monthly report. Build the thing you've explained three times and nobody got.

Don't look like every AI site: go to getdesign.md, pick a style like Stripe, Notion, or Linear, drop the file in your folder, tell Claude to use it for all the styling. Stop typing "make it look good."

What it costs: $20/month is enough to start, new chat for every task, point at your files instead of pasting big text, type /usage to see where you stand. You pay for every wrong turn, ask for the plan first.

Delete the belief that Code means coding, the one giant chat you never close, the six hour build you never open, and the idea you'll start when things calm down.
