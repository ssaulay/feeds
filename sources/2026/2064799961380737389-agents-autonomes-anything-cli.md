# Des agents IA développent et publient des apps sans supervision humaine via Anything CLI

> Post de **@anything** — [voir sur X](https://x.com/anything/status/2064799961380737389)

## Résumé

Le post annonce que plusieurs agents IA (Claude Code, OpenClaw, Codex, Hermes) peuvent désormais concevoir, construire et publier des applications de bout en bout grâce à l'Anything CLI. L'accent est mis sur l'absence totale d'intervention humaine dans ce processus de développement.

- Plusieurs agents IA concurrents peuvent désormais interagir avec un même outil CLI pour développer des apps.
- Le cycle complet (design, build, publish) serait automatisable sans supervision humaine.
- Anything CLI se positionne comme une infrastructure d'orchestration pour agents de développement autonomes.
