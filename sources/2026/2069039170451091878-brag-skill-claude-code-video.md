# /brag : générer automatiquement une vidéo de lancement depuis Claude Code

> Post de **@Arcane_Aii** — [voir sur X](https://x.com/Arcane_Aii/status/2069039170451091878)

## Résumé

Un skill Claude Code nommé /brag transforme n'importe quel side project en une vidéo de lancement d'environ 20 secondes, avec musique, animations et effets sonores. Il s'appuie sur HyperFrames, le moteur open-source HTML-to-video de HeyGen, et propose plusieurs styles prédéfinis. L'outil est gratuit, open source, et inclut des démos pour tester rapidement sans projet réel.

- Un simple prompt ('/brag about this') suffit pour générer une vidéo de présentation professionnelle d'un projet
- L'outil résout le problème des posts de lancement peu engageants avec de simples screenshots statiques
- Basé sur HyperFrames (HeyGen), un moteur open-source de conversion HTML vers vidéo
- Propose plusieurs presets de style et génère aussi le copy prêt à partager
