# Cat Wu (Anthropic) : du prompting aux graphes d'agents auto-améliorants

> Post de **@ZoriaHartson** — [voir sur X](https://x.com/ZoriaHartson/status/2107546605721174178)

## Résumé

Post à forte tonalité hype annonçant que le prompting classique serait dépassé chez Anthropic, remplacé par des boucles et graphes d'agents auto-améliorants. Une Product Manager d'Anthropic, Cat Wu, est montrée sur scène en train de présenter une démo live construisant un système Claude Code complet en 10 minutes. Le contenu manque de preuves concrètes (pas de repo, pas de lien vers la démo réelle) et relève surtout du marketing/FOMO autour des agentic workflows.

## Idées clés

- Anthropic affirmerait que la majorité de ses ingénieurs utilisent déjà des boucles self-improving plutôt que du prompting simple.
- La tendance annoncée est une progression : Agents → Loops → Graphs → Self-Improving Systems.
- Une démo live partirait d'un terminal vide pour construire un système agentique complet avec Claude Code.
- Le post a une forte tonalité promotionnelle/FOMO ('free window is closing') à prendre avec recul critique, sans source vérifiable directe vers la démo.
