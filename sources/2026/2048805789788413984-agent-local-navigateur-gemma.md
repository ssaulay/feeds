# Agent IA local dans le navigateur avec Gemma et WebGPU

> Post de **@googlegemma** — [voir sur X](https://x.com/googlegemma/status/2048805789788413984)

## Résumé

Un agent 100% local fonctionnant directement dans le navigateur grâce à Gemma 4 E2B et WebGPU, sans besoin de serveur. Il utilise le tool calling natif pour rechercher dans l'historique de navigation, lire et résumer des pages, et gérer les onglets.

## Idées clés

- L'exécution locale via WebGPU permet de faire tourner un LLM directement dans le navigateur sans backend serveur
- Le tool calling natif permet à l'agent d'interagir avec des fonctionnalités du navigateur (historique, onglets, contenu des pages)
- Un modèle compact comme Gemma 4 E2B suffit pour des tâches d'agent pratiques côté client
- Cette approche élimine les enjeux de confidentialité liés à l'envoi de données de navigation vers des serveurs distants
