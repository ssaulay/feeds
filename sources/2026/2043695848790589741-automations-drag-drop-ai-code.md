# Lancement d'Automations : workflows via drag-and-drop, IA ou code (Claude Code, Cursor, Codex)

> Post de **@zenorocha** — [voir sur X](https://x.com/zenorocha/status/2043695848790589741)

## Résumé

Annonce d'une nouvelle fonctionnalité "Automations" qui se distingue des outils de marketing automation traditionnels en proposant trois façons de construire des workflows : éditeur visuel drag-and-drop, langage naturel avec IA, ou code directement via des outils comme Claude Code, Cursor ou Codex. Cette approche hybride vise à combiner accessibilité et puissance pour différents profils d'utilisateurs.

## Idées clés

- Une même fonctionnalité peut offrir plusieurs niveaux d'abstraction (visuel, langage naturel, code) pour toucher différents utilisateurs.
- L'intégration d'outils de codage IA comme Claude Code ou Cursor dans un produit SaaS illustre la convergence entre no-code et développement assisté par IA.
- Se positionner en opposition aux "old-school" outils marketing automation est une stratégie de différenciation produit.

## Citations
