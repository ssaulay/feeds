# CleanShot 5.0 lance le Studio Mode pour des captures vidéo pro

> Post de **@CleanShot** — [voir sur X](https://x.com/CleanShot/status/2094803447920967862)

## Résumé

CleanShot 5.0 introduit un mode Studio permettant de transformer facilement un enregistrement d'écran simple en vidéo professionnelle et soignée. L'interface montrée permet de personnaliser le curseur (taille, style, affichage) et le type de mouvement (Natural ou Smooth). Cette fonctionnalité est disponible immédiatement sur tous les plans, sans nécessiter d'abonnement.

## Idées clés

- Le Studio Mode permet de personnaliser finement l'apparence du curseur dans les enregistrements (taille jusqu'à 3x, style, visibilité).
- Deux modes de mouvement du curseur sont proposés : Natural et Smooth, pour adapter le rendu visuel de la vidéo.
- La fonctionnalité est incluse sans surcoût, accessible sur tous les plans existants dès la sortie.
- L'outil vise à simplifier la production de vidéos professionnelles à partir de captures d'écran basiques.
