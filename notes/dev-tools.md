## Synthèse

Cette note couvre des outils facilitant différentes étapes du cycle de vie d'un projet dev, du déploiement (web et mobile) à la communication, en passant par la génération d'applications, le traitement de documents, la capture vidéo, les modalités de saisie alternatives et l'optimisation des workflows IA.

**Déploiement web** : Vercel Drop permet de déployer un fichier ou dossier en le glissant directement dans le navigateur, sans Git, CLI ni configuration locale préalable. L'outil détecte automatiquement le framework utilisé — Next.js, mais aussi les exports d'outils comme Bolt.new, Claude Design ou Google Stitch — et lance le build correspondant ; les sites statiques sans framework sont déployés tels quels, sans étape de build. Si aucun `index.html` n'est présent à la racine, l'utilisateur choisit lui-même la page racine du site. Chaque drop crée un nouveau projet avec une URL de production live en quelques secondes ; un dépôt Git peut ensuite y être connecté pour passer à des déploiements automatiques.

**Build et déploiement iOS sans Mac** : le dépôt open source omarchy-apple-dev permet de développer, builder et déployer des apps SwiftUI entièrement sur Linux (Omarchy/Arch), sans jamais utiliser macOS ni Xcode. Un script d'installation (`install-toolchain.sh`) met en place Swift, xtool, pymobiledevice3 et LLDB pour reproduire la chaîne de build iOS, le projet réimplémentant au passage des outils propriétaires Apple (actool, ibtool, momc). Seul prérequis externe : un téléchargement unique du fichier Xcode.xip officiel d'Apple pour en extraire le SDK iOS — aucune exécution de macOS ou d'Xcode n'est nécessaire. Le déploiement sur iPhone physique via USB fonctionne avec un simple Apple ID gratuit, sans abonnement développeur payant ; en revanche le déploiement sans fil reste bloqué par Apple pour les hôtes Linux, le tunnel RemotePairing étant réservé aux Mac. `ship.sh` automatise build release, compilation d'icônes/assets, signature et upload vers App Store Connect, workflow validé avec des apps réelles publiées sur l'App Store (NetNewsWire, IceCubesApp, Mastodon). Un outil companion, `xcodeproj2xtool.py`, convertit un projet Xcode existant pour migrer vers ce workflow Linux. Point de friction documenté : changer de toolchain Swift casse l'enregistrement du SDK, résolu via une commande `--repair` qui réenregistre le cache sans nouveau téléchargement. Contrairement à Vercel Drop, qui vise la simplicité maximale pour du déploiement web, cet outil reconstruit une chaîne de build native complexe sur un OS non supporté officiellement, pour s'affranchir totalement de la dépendance matérielle/logicielle à macOS.

**Génération d'applications par IA** : Higgsfield Apps, présentée comme la plus grosse release de Higgsfield à ce jour, permet de générer des applications complètes intégrant nativement les modèles d'image et vidéo de la plateforme. Le moteur Fable 5 conçoit le code applicatif au niveau d'un ingénieur senior, couvrant un large spectre : sites web complexes, extensions navigateur, plugins, applications desktop et mobile, avec déploiement direct une fois l'app générée. La solution est accessible via Supercomputer et, surtout, directement depuis Claude grâce au MCP (Model Context Protocol) de Higgsfield — une intégration qui rejoint la tendance d'orchestration d'outils IA complémentaires autour de Claude Code déjà observée avec NotebookLM et anydoc (voir plus bas).

**Communication / marketing produit** : le skill Claude Code `/brag` génère automatiquement une vidéo de lancement (~20 secondes, musique, animations, effets sonores) à partir d'un simple prompt ("/brag about this"), pour n'importe quel side project. Il s'appuie sur HyperFrames, le moteur open-source HTML-to-video de HeyGen, propose plusieurs presets de style et génère aussi le copy prêt à partager. L'outil vise à remplacer les posts de lancement peu engageants (simples screenshots statiques) par un format vidéo professionnel. Gratuit, open source, avec des démos incluses pour tester sans projet réel.

**Capture d'écran et vidéo** : CleanShot 5.0 introduit un Studio Mode permettant de transformer un enregistrement d'écran basique en vidéo soignée et professionnelle. L'interface permet de personnaliser finement le curseur — taille (jusqu'à 3x), style, visibilité — ainsi que son type de mouvement (Natural ou Smooth), pour ajuster le rendu visuel final. Contrairement au skill `/brag` qui génère automatiquement une vidéo de lancement à partir de code, CleanShot 5.0 se positionne sur l'édition manuelle et le rendu de captures d'écran existantes (démos, tutoriels). La fonctionnalité est disponible immédiatement sur tous les plans, sans surcoût ni abonnement additionnel.

**Traitement de documents pour agents IA** : Firecrawl a open-sourcé anydoc, un convertisseur universel de documents (docx, pptx, xlsx, PDF, epub, rtf... — 14 formats) vers Markdown (GFM), écrit en Rust pur, 100% local et sans modèle ML. Ses performances sont remarquables (médiane ~5ms par fichier vs ~1100ms pour LibreOffice, soit 500 docx convertis en 1,7s), ce qui permet une intégration *synchrone* dans une boucle d'agent IA sans file d'attente asynchrone complexe — un choix d'architecture qui tranche avec les outils reposant sur des modèles ML plus lourds. La détection de format s'appuie sur l'analyse du contenu plutôt que sur l'extension, ce qui permet de rejeter proprement les faux fichiers et de repérer des documents corrompus dans un dossier.
